A program that writes one elevator pitch from a city pigeon to investors into `/output/entry.txt` — the pigeon's startup, CooPay, turns every statue into a subscription perch.

## The line

> CooPay turns every statue into a subscription perch — pigeons pay rent in breadcrumbs, investors pay cash, and I'm the CEO, the fleet, and the only shareholder.

The pigeon is the whole company at once: founder, workforce, and sole shareholder. The investors pay real cash; the pigeons pay in breadcrumbs.

## How to run

Requires Node 22 or newer. No dependencies, no network.

```sh
node main.ts
```

It writes the pitch (160 characters, one line, no trailing newline) to `/output/entry.txt`.
